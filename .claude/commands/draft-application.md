# draft-application

Read the grant, tasks and history. Draft only known context and leave missing narrative for the operator. No invented beneficiaries, outcomes or impact figures.

Run `node scripts/grants.mjs draft-application <grant>`. Replace placeholders with the operator's values. Append `--json` when validating results. Every write needs an actor. If ambiguous, show matches and ask. Never send, submit or make a payment. Drafts stay local.
