# weekly-review

Run attention, awards and reports-due, then weekly-review. Separate currencies. Name each decision, owner and deadline. Never present an unknown amount as zero.

Run `node scripts/grants.mjs weekly-review`. Replace placeholders with the operator's values. Append `--json` when validating results. Every write needs an actor. If ambiguous, show matches and ask. Never send, submit or make a payment. Drafts stay local.
