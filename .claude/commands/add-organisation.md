# add-organisation

Read the affected records before changing them. Use full ids after resolving a name. Report the actual result and any missing evidence.

Run `node scripts/grants.mjs add-organisation <name> --jurisdiction=NZ|AU --balance-date=YYYY-MM-DD --actor=name`. Replace placeholders with the operator's values. Append `--json` when validating results. Every write needs an actor. If ambiguous, show matches and ask. Never send, submit or make a payment. Drafts stay local.
