# set-budget

Read budgets and history first. The agreed award determines permissible categories, not the software. Record the approving person as actor.

Run `node scripts/grants.mjs set-budget <grant> --category=name --amount=100.00 --actor=name`. Replace placeholders with the operator's values. Append `--json` when validating results. Every write needs an actor. If ambiguous, show matches and ask. Never send, submit or make a payment. Drafts stay local.
