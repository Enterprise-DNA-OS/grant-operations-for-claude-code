# Why this desk has no front end

The operator asks for deadlines, budget exceptions or an acquittal draft. A coding agent reads the database through one CLI. Read-only HTML gives the board a printable review without another application to maintain.

A screen gives mobile data entry, offline capture, shared permissions, drag and drop, attachments and live collaboration. This base supplies none of those. Embedded mode is a local, single-operator desk. Enterprise DNA scopes the screens, connections, access control and managed database for a shared installation. It does not replace a funder-discovery subscription or accounting system.

Change `brand.json` once for names, colours and logo. `npm run view` writes to views; `npm run docs` writes to docs-out. Keep those files private. They contain records and are not hosted automatically.
